04 / QUICK ANSWERS

Before you jump in.

Which operating systems are supported? +

NOVA Client is designed for Windows 10 and Windows 11 (64-bit). Check the system requirements for your selected release before installing.

How do I install the client? +

Download the installer from the official release page, open the downloaded file, and follow the setup instructions. Close the game before updating, then restart the launcher after installation.

How do I check for updates? +

Open the launcher and check the version shown on the home screen. Visit the release notes for the latest version and restart the launcher after applying an update.

Where can I get help if something goes wrong? +

Check the release notes and troubleshooting information first. If the issue continues, contact the project's support team and include your Windows version and a short description of the problem.
