NOVA CLIENT — FICTIONAL LAUNCHER WEBSITE CONCEPT
================================================

This is a static website template for an independent client-style project. It is not
Lunar Client and is not affiliated with Mojang/Microsoft. No real launcher or installer
is included in this website package; the download button opens an unavailable notice.

FILES
-----
index.html  Main page, release notes, feature cards, FAQ
style.css   Neon dark theme, responsive layout, animated background
script.js   Download notice modal and mobile navigation

PREVIEW ON WINDOWS
------------------
1. Extract the ZIP.
2. Open the folder.
3. Double-click index.html to preview it in your browser.
   Internet access is needed for the optional Google Fonts; fallback fonts work offline.

EDITING
-------
Use Notepad or VS Code to edit index.html and style.css if you need to adjust the page layout
or styling. Ensure any published product claims and release notes accurately describe your
project and do not imply affiliation with another client or game publisher.

FREE HOSTING WITH NETLIFY
-------------------------
1. Visit https://app.netlify.com/drop
2. Sign in if prompted.
3. Upload the extracted site folder if folder upload is supported, or upload a ZIP with
   index.html at the ZIP root.
4. Open the generated public URL and test the site on desktop and mobile.
5. Re-upload the updated site folder when you make changes.

No Node.js, Git, or build tools are required.
